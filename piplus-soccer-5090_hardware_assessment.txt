PiPlus 8x RTX 5090 服务器多卡训练验收
=====================================

检查时间：2026-07-28
主机：piplus-soccer-5090 / XN-5090-GPU9


一、最终结论
------------

服务器现在已经可以运行当前 UFO 框架的单机 8 卡训练，但适合的是“稳定功能性训练”，
不适合期待高效线性扩展的 8 卡训练。

推荐正式训练默认使用：
  NCCL_P2P_DISABLE=1
  NCCL_SHM_DISABLE=1
  NCCL_IB_DISABLE=1
  NCCL_SOCKET_IFNAME=ens49
  NCCL_SOCKET_NTHREADS=4
  NCCL_NSOCKS_PERTHREAD=4
  NCCL_ALGO=Ring
  NCCL_PROTO=Simple

RoCE/RDMA 可以被 NCCL 使用，但实测明显慢于 Socket；SHM 路径会触发 CUDA
illegal memory access，不能用于正式训练。


二、硬件和软件状态
------------------

- GPU：8 x RTX 5090，单卡 31.4 GiB，PCIe 5.0 x16。
- 拓扑：GPU 0-3 在 NUMA 0，GPU 4-7 在 NUMA 1；GPU 间 P2P 全部为 CNS，
  无可用 CUDA P2P/NVLink。
- CPU：2 x Xeon Platinum 8470N，共 104 核 / 208 线程。
- 内存：377 GiB；数据盘：3.5 TiB NVMe。
- RDMA：Mellanox ConnectX-3，mlx4_0，10GbE RoCE，ens49，位于 NUMA 1。
- NVIDIA 驱动：580.173.02 Open DKMS，已为当前 6.8.0-88 内核构建。
- Python：PyTorch 2.7.1+cu128，CUDA runtime 12.8，NCCL 2.26.2。
- 远端环境备份：`/data/hejunfu/train_env.sh.before-nccl-20260728`。
- 旧 Python 环境备份：`/data/hejunfu/UFO-main/.venv.broken-20260728`。


三、实测结果
------------

1. CUDA 基础检查

- `nvidia-smi` 正常识别 8 张 RTX 5090。
- 8 张 GPU 均完成 CUDA tensor 分配和同步。

2. NCCL Socket，8 卡，禁用 P2P/SHM/IB

- 256 MiB all-reduce：2.819 GiB/s，测试通过。
- 64 个 1 MiB collective：0.450 GiB/s，测试通过。
- 使用 `ens49`，4 threads x 4 sockets。

3. NCCL Socket，同 NUMA 四卡

- GPU 0-3：256 MiB all-reduce 3.606 GiB/s。
- GPU 4-7：256 MiB all-reduce 3.945 GiB/s。
- 相比同 NUMA 四卡，跨 NUMA 八卡约下降 22%-29%。

4. NCCL RoCE/IB，8 卡

- NCCL 日志明确显示：`Using network IB`、`mlx4_0:1/RoCE`。
- 256 MiB all-reduce：0.180 GiB/s，测试通过但性能很差。
- 日志同时显示：`GPU Direct RDMA Disabled`，当前是主机内存中转，不是 GPU Direct RDMA。

5. NCCL SHM，8 卡

- 日志显示 `via SHM/direct/direct`。
- 首个 64 MiB all-reduce 即触发 `CUDA error: an illegal memory access was encountered`。
- 该路径不可用于正式训练。

6. UFO 框架 8 卡 smoke

- 8 个 worker 全部启动，`world_size=8`。
- NCCL 使用 Socket，训练环境成功初始化。
- smoke 以返回码 0 正常结束，无 NCCL timeout、CUDA 错误或 rank 提前退出。


四、判断和建议
--------------

- 八卡“能不能训练”：可以，当前 UFO 训练入口已验收通过。
- 八卡“是否高效”：不高效。主要限制是无 P2P、跨双 NUMA、单口 10Gb RoCE，
  且 RoCE 实测只有 0.18 GiB/s。
- 正式训练应保持 P2P、SHM、IB 禁用，使用经过调优的 Socket 配置。
- 不建议仅为追求速度强行打开 SHM 或 RoCE；SHM 会崩溃，RoCE 比 Socket 慢约 15 倍。
- 如需进一步提升八卡扩展效率，需要每个 NUMA 节点配置高速 100Gb 以上 RoCE/InfiniBand，
  或使用带 GPU 高速互联的服务器平台。
